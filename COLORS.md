# Vibe Commerce Color Palette - boAt Inspired

## Design Philosophy
A clean, modern color scheme inspired by boAt's aesthetic using minimal white and light gray with strong black typography and subtle red accents. The palette conveys premium quality, boldness, and contemporary style.

## Color Variables

### Light Mode (Default)
```css
--background: #ffffff        /* Pure white base - main background */
--foreground: #000000        /* Strong black - primary text */
--primary: #000000           /* Black primary - headers, buttons */
--secondary: #f8f9fa         /* Light gray - secondary elements */
--accent: #dc2626            /* Red accent - highlights, CTAs */
--muted: #f8f9fa             /* Light gray - subtle backgrounds */
--card: #ffffff              /* Pure white - card backgrounds */
--border: #e9ecef            /* Light gray - borders */
--surface: #f8f9fa           /* Light gray surface */
```

### Dark Mode
```css
--background: #000000        /* Pure black background */
--foreground: #ffffff        /* White text */
--primary: #ffffff           /* White primary (inverted) */
--secondary: #1a1a1a         /* Dark gray secondary */
--accent: #dc2626            /* Red accent */
--card: #111111              /* Dark gray cards */
--border: #333333            /* Dark gray borders */
```

## Usage Guidelines

### Primary Colors
- **Pure Black (#000000)**: Headers, primary text, navigation
- **Pure White (#ffffff)**: Main background, creates clean minimalism
- **Red Accent (#dc2626)**: CTAs, highlights, important elements

### Typography
- **Headings**: Bold black typography for strong hierarchy
- **Body text**: Black (#000000) for maximum readability
- **Muted text**: Gray (#6c757d) for secondary information

### Interactive Elements
- **Primary Buttons**: Red background with white text
- **Secondary Buttons**: Black outline with black text
- **Links**: Red accent color with smooth hover effects
- **Focus states**: Red ring for accessibility

### Cards & Surfaces
- **Cards**: Pure white (#ffffff) with subtle shadows
- **Subtle surfaces**: Light gray (#f8f9fa)
- **Borders**: Clean light gray borders (#e9ecef)

## Layout Principles
- **Grid-based**: Sharp alignment and spacious layouts
- **Minimal**: Clean, uncluttered design
- **Bold Typography**: Strong contrast and hierarchy
- **Smooth Interactions**: Subtle hover effects and transitions

## Accessibility
- High contrast black/white ensures WCAG AAA compliance
- Red accents provide clear visual hierarchy
- Focus indicators use high-contrast red color
- Text remains crisp and readable across all devices

## Brand Personality
- **Bold**: Strong black typography commands attention
- **Modern**: Clean, contemporary aesthetic
- **Premium**: Sophisticated minimalism
- **Energetic**: Red accents add vibrancy and action
