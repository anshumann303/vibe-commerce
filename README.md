Vibe Commerce – Full-Stack E-Commerce Web App

Vibe Commerce is a modern full-stack e-commerce web application built to showcase a seamless shopping experience — from browsing products to managing the cart and completing mock checkouts.
It features a premium dark theme, smooth UI transitions, and an optimized architecture integrating frontend, backend, and database layers.

🚀 Features

🛒 Add / Remove / Update items in cart

💰 Real-time price calculation and product totals

🧭 Category pages and responsive navigation

🌙 Premium dark theme with modern UI elements

📦 RESTful API integration (Products, Cart, Checkout)

💾 Persistent mock database

🧱 Modular folder structure for scalability

⚙️ Environment variables & TypeScript configuration

🧩 Tech Stack
Frontend

⚛️ React (Vite + TypeScript)

🎨 Tailwind CSS

🧠 Context API / useReducer for state management

🔍 React Router for navigation

✨ Framer Motion for animations

Backend

🟩 Node.js + Express.js

🗄️ MongoDB / SQLite (mock DB)

🔐 Environment configuration with .env

Build Tools & Config

🧰 ESLint & TypeScript configs

⚡ Vite for fast development and builds

📁 Folder Structure
Vibe-Commerce/
├── backend/              # Express backend APIs
├── public/               # Static assets
├── src/                  # React frontend source code
│   ├── components/       # Reusable UI components
│   ├── pages/            # Category, Product, Cart pages
│   ├── context/          # Global app state
│   ├── utils/            # Helper functions
│   └── styles/           # Tailwind & theme setup
├── .env                  # Environment variables
├── package.json          # Project dependencies
├── vite.config.ts        # Vite configuration
├── tsconfig.*.json       # TypeScript configs
└── COLORS.md             # Color palette reference# React + TypeScript + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.
